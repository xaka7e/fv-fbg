# FBG Bau — QA V4.1

Дата проверки: 13.09.2026

## Главная страница — responsive

Проверены viewport-ширины:
`320`, `360`, `375`, `390`, `393`, `414`, `430`, `768`, `1024`, `1280`, `1440`, `1920` px.

Результат:
- горизонтального скролла нет;
- sticky hero остаётся `position: sticky`;
- на mobile показывается MENU, на desktop основная навигация;
- DOKA-сцена не расширяет документ за viewport;
- 320 px больше не ломает блок вакансий;
- JavaScript ошибок при первичной загрузке в тестовом рендере не дал.

## Внутренние страницы

## Навигация и код

- Проверено 216 локальных `href/src` — отсутствующих локальных файлов/страниц: 0.
- `script.js`, `site.js`, `enhancements.js` проходят синтаксическую проверку Node.
- Мобильное меню проверено на 320, 390 и 768 px: верхняя граница меню совпадает с нижней границей шапки.
- Escape закрывает открытое меню.

## Что специально не менялось

- Визуальная концепция V4 сохранена.
- Тексты/структура основных разделов не переписывались под версию Astra.
- Внешние проектные фотографии пока остаются внешними URL. Перед реальным production запуском лучше заменить их на разрешённые локальные оригиналы FBG.
